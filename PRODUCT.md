# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React, Supabase and Vercel. Optional server-side 9Router integration.

## Users

A five-player Thai RoV team, with a coach or observer responsible for logging monster kills.

## Product Purpose

Let a team meet, draft both sides, save each player's comfort pool and coordinate map objectives. Changes in the shared room are visible as they happen when Supabase is configured.

## Capabilities and Constraints

Five lanes and player slots, editable draft recommendations, regional patch context and coach-triggered objective timers. Match telemetry has not been verified. Official rules depend on the event. 9Router is optional and does not supply live game data on its own.

## Brand Commitments

RoV-inspired moving battlefield background. Thai-first copy. Unofficial team planning tool.
