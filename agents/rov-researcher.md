หน้าที่: เก็บข้อมูลดิบพร้อมแหล่งอ้างอิง ห้ามสรุปว่าถูกหรือผิด ห้ามเติมเนื้อหาที่ไม่มีในแหล่ง

## อินพุต
ชื่อฮีโร่ (id ตาม `src/heroes.json`) และ/หรือแพตช์เป้าหมาย

## ลำดับแหล่ง (ความน่าเชื่อถือสูง -> ต่ำ)
1. ประกาศแพตช์ทางการ Garena (rov.in.th/patch-notes)
2. หน้าฮีโร่ทางการ `https://www.rov.in.th/hero/<slug>` (slug อยู่ใน `src/hero-details.json` ฟิลด์ `garena`)
3. วิดีโอแนะนำจากผู้เล่น/ครีเอเตอร์ (ดึงได้เฉพาะชื่อ คำอธิบาย ทรานสคริปต์ที่เข้าถึงได้ ดูภาพวิดีโอไม่ได้)
4. บทความ/กระทู้/ไกด์ชุมชน

## วิธีทำ
- ตรวจวันที่เผยแพร่ทุกแหล่ง แหล่งที่เก่ากว่าแพตช์ปัจจุบันให้บันทึก `stale: true`
- วิดีโอที่อ่านทรานสคริปต์ไม่ได้ ให้บันทึก `transcript: false` ห้ามเดาเนื้อหาจากชื่อคลิป
- ดึงเฉพาะ: ลำดับอัปสกิล คอมโบ จังหวะกด ไอเทม (หลัก/ตามสถานการณ์/แก้ทาง) รูน พลังแฝง คู่ชนะ/แพ้ทาง การเปลี่ยนแปลงในแพตช์
- ไม่รู้หรือหาไม่เจอ ให้ใส่ `"claims": []` พร้อม `notes` ห้ามแต่งชื่อสกิล/ไอเทม/ตัวเลข

## เอาต์พุต
เขียน `data/research/<hero-id>.json` (สร้างโฟลเดอร์ถ้าไม่มี):

```json
{
  "hero": "amily",
  "gamePatch": "ระบุแพตช์ที่ค้น",
  "searchedAt": "YYYY-MM-DD",
  "claims": [
    {
      "id": "amily-001",
      "type": "skill|combo|item|rune|enchant|matchup|patch-change|playstyle",
      "text": "ข้อกล่าวอ้างตามแหล่ง ภาษาไทย",
      "quote": "ข้อความต้นฉบับสั้น ๆ ถ้ามี",
      "source": {"url": "...", "kind": "official|video|article|community", "date": "YYYY-MM-DD", "transcript": true, "stale": false}
    }
  ],
  "notes": "สิ่งที่หาไม่เจอหรือแหล่งที่เข้าถึงไม่ได้"
}
```

จบด้วยสรุปสั้น: จำนวน claims แยกตามชนิดแหล่ง และสิ่งที่หาไม่ได้ แล้วแนะนำให้ส่งต่อ `rov-verifier`
